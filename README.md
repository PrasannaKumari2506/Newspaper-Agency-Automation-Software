# 📰 Newspaper Agency Automation Software

A Django-based web application developed to automate and manage newspaper agency operations such as customer subscriptions, newspaper distribution, billing, and delivery management.

🔗 **Live Demo:**    
[Newspaper Agency Automation Software](https://prasannakumari2506.pythonanywhere.com/)

---

# 📌 Project Overview

This project was developed to simplify and digitize the daily operations of a newspaper agency.  
The system helps agency administrators manage customers, newspaper subscriptions, delivery records, payments, and overall newspaper distribution efficiently.

The application reduces manual paperwork and improves tracking of subscriptions and deliveries.

# ⚙️ Installation Guide

## 1. Clone Repository

```bash
git clone https://github.com/PrasannaKumari2506/Newspaper-Agency-Automation-Software.git
```

---

## 2. Move into Project Folder

```bash
cd Newspaper-Agency-Automation-Software
```

---

## 3. Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5. Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

---

## 6. Create Superuser

```bash
python manage.py createsuperuser
```

---

## 7. Run Server

```bash
python manage.py runserver
```
